Container image (ghcr.io/timothydodd/couchside-capture)
------------------------------------------------------

The image is based on Alpine Linux and adds these programs. couchside-capture
runs them as separate processes; it doesn't link them.

- FFmpeg (Alpine package "ffmpeg"): encodes the captured frames to HLS.
  GPL v2 or later as built by Alpine (configured with --enable-gpl); see
  https://ffmpeg.org/legal.html. The H.264 encoding uses libx264 (Alpine
  package "x264-libs", GPL v2 or later, https://www.videolan.org/developers/x264.html);
  the other libraries ffmpeg links are pulled in as Alpine package
  dependencies, each under its own license. The build's version and configure
  flags are recorded in the image at
  /usr/share/licenses/couchside-capture/ffmpeg-configuration.txt. Source:
  https://ffmpeg.org, https://code.videolan.org/videolan/x264 and the Alpine
  aports tree at the package versions named there,
  https://gitlab.alpinelinux.org/alpine/aports (community/ffmpeg,
  community/x264). These programs are distributed unmodified, exactly as
  Alpine builds them.

- Chromium (Alpine package "chromium"): renders the page. BSD-3-Clause and
  the licenses of its bundled components
  (https://chromium.googlesource.com/chromium/src/+/HEAD/LICENSE). The full
  list of those components and their license texts is built into the browser
  and shown at chrome://credits. Source:
  https://chromium.googlesource.com/chromium/src and aports (community/chromium).

- Noto fonts (Alpine packages "font-noto", "font-noto-emoji"): SIL Open Font
  License 1.1. https://github.com/notofonts, https://github.com/googlefonts/noto-emoji.

- Intel Media Driver, libva-intel-driver and Mesa's VA driver (x86-64 images
  only): MIT (the Intel Media Driver also BSD-3-Clause).
  https://github.com/intel/media-driver,
  https://github.com/intel/intel-vaapi-driver, https://mesa3d.org.

- Alpine Linux base packages (musl, busybox, ca-certificates, tzdata and the
  libraries the programs above use), each under its own license, recorded in
  the image's package database (`apk info -a <package>` shows a package's
  license). Every package and version in the image is listed in
  /usr/share/licenses/couchside-capture/packages.txt. Source:
  https://gitlab.alpinelinux.org/alpine/aports.
